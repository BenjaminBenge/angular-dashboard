# NSSF Admin Dashboard

An Angular admin dashboard for the National Social Security Fund that tracks member registration, contributions, benefit payouts, employer compliance, and fund investments.

## Tech Stack

- Angular 22 (standalone components, signals, RxJS, HttpClient)
- TypeScript, SCSS, HTML5
- Vitest for unit testing

## Development

```bash
ng serve
```

Open `http://localhost:4200/` in your browser.

## Build

```bash
ng build
```

Build artifacts are written to `dist/angular-dashboard`.
